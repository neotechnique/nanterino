# Points de tri : textile, piles, verre

- Catégorie : point de collecte
- Mots-clés : textile, vêtements, chaussures, linge, borne textile, piles, batteries, verre, bouteilles, bocaux, conteneur, recyclage, trier, point de collecte
- Adresse : plusieurs points dans la ville ; la carte « CartoPOLD » de Paris Ouest La Défense permet de trouver le plus proche.
- Horaires : non précisé
- Description : Il y a plusieurs bornes dans la ville pour déposer les vêtements, les piles et le verre. Pour trouver la plus proche, consultez la carte en ligne de Paris Ouest La Défense.
- Ce qu'on y fait :
  - Textiles (vêtements, linge, chaussures, maroquinerie) : propres, secs, en sacs fermés de moins de 50 litres, dans les bornes dédiées.
  - Piles : dans les bacs des bâtiments publics, de certains commerces, ou à la déchèterie.
  - Verre : bouteilles, bocaux et pots sans bouchon ni couvercle ; pas de vaisselle, de miroirs ni de vitres.
- Accès : non précisé.
