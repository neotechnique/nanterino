# Trier les emballages et les papiers (bac jaune)

- Catégorie : bonne pratique
- Mots-clés : poubelle, jaune, bac jaune, recyclage, recycler, trier, tri, plastique, bouteille, carton, papier, conserve, canette, brique, emballage, barquette
- Description : À Nanterre, tous les papiers et tous les emballages vont dans le bac à couvercle jaune, sauf le verre. Il suffit de bien les vider, pas besoin de les laver.
- Ce qu'il faut savoir :
  - Bac jaune : papiers (journaux, prospectus, enveloppes), plastiques (bouteilles, barquettes, films, sachets), cartons et briques alimentaires, métaux (conserves, canettes, aérosols) et petits emballages métalliques (capsules, opercules).
  - On dépose en vrac, sans sac, et on n'imbrique pas les emballages les uns dans les autres.
  - Un bac jaune avec trop d'erreurs de tri n'est pas collecté. En cas de doute sur un emballage, le bac gris est conseillé.
  - Le verre ne va pas dans le bac jaune : il va dans les bornes à verre.
