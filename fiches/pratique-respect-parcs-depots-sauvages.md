# Respecter les parcs et ne pas laisser de dépôts sauvages

- Catégorie : bonne pratique
- Mots-clés : parc, square, espaces verts, pigeons, nourrir animaux, pique-nique, déchets, dépôt sauvage, amende, chien, déjections, arbre, signaler, incivilité
- Description : Dans les parcs de Nanterre, on ramasse ses déchets et on ne nourrit pas les animaux. Les dépôts sauvages de déchets sont interdits et sévèrement sanctionnés.
- Ce qu'il faut savoir :
  - Il est interdit de nourrir pigeons, corneilles, chats ou rats.
  - Pique-nique autorisé si tous les déchets sont ramassés ; on n'abîme pas les arbres et les plantations.
  - Les propriétaires de chiens ramassent les déjections.
  - Dépôt sauvage : amende pouvant aller jusqu'à 15 000 euros, plus le coût de l'enlèvement. Pour en signaler un : formulaire « Signaler une incivilité » sur nanterre.fr.
- Où s'adresser : Hôtel de ville, 01 47 29 50 50 ; formulaire en ligne sur nanterre.fr
- Source et date de vérification : https://www.nanterre.fr/incivilites-reglementation-et-signalement ; arrêté AR2024-04 de la Ville de Nanterre, 16/10/2026
