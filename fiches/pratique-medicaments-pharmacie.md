# Rapporter ses médicaments à la pharmacie

- Catégorie : bonne pratique
- Mots-clés : médicaments, pharmacie, périmé, sirop, comprimé, pommade, armoire à pharmacie, toilettes, poubelle
- Description : Vos médicaments périmés ou inutilisés se rapportent gratuitement à la pharmacie. Ne les jetez ni à la poubelle ni dans les toilettes.
- Ce qu'il faut savoir :
  - Toutes les pharmacies les reprennent : comprimés, gélules, sirops, pommades, sprays.
  - Rapportez-les sans la boîte en carton ni la notice, qui vont dans le bac jaune.
  - Jetés dans la poubelle ou les toilettes, ils polluent l'eau et les sols.
- Où s'adresser : n'importe quelle pharmacie
