# Samples: VSCO 2 Community Edition (CC0)

The WAV files in this folder are converted excerpts (mono, 16-bit, 22050 Hz, trimmed to a few
seconds, peak-normalized per instrument) from **Versilian Studios Chamber Orchestra 2 - Community
Edition** by Versilian Studios / Sam Gossner, source https://github.com/sgossner/VSCO-2-CE
(downloaded 2026-10-14), released under **CC0 1.0 Universal** (public domain dedication).
No attribution is legally required; it is kept here for provenance.

`manifest.json` lists every file with its source file name and its root note (MIDI number;
VSCO note labels are one octave below scientific pitch, so label + 12 = MIDI root).
